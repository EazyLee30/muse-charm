02 / GET STARTED

三步开始玩

  1. 刷入懒人包固件。
    解压 Release ZIP，按包内 开始使用.md 安装 esptool 并刷写。首次安装用 factory 镜像；已有相同分区表用 app 镜像。这里只配置，不执行刷机。
  2. 连接 USB，填写自己的 token。
    使用电脑 Chrome 或 Edge。点击左侧连接，选择 ESP32 的 USB Serial/JTAG 串口，保存后板子会重启。
  3. 到 Muse App 添加设备。
    添加 MuseGadget-Disp-XXXXXX，提示时短按 BOOT，再选择 2.4GHz Wi-Fi。按住 KEY 说话，松开发送。

保存成功只代表板子已保存凭证；格式校验不会验证账号权限。真正可用性由 Muse 配对和 TTS 服务确认。更换账号 token 后，请在 Muse App 重新添加设备。

连接不上？

Safari / Firefox 不支持此页面的 Web Serial。使用桌面 Chrome / Edge，关闭占用串口的软件，确认数据线支持数据传输。配置时板子应正常运行，不能停在 BOOT 下载模式。

若页面提示固件不支持，请先刷入 v0.8.0。若本地文件无法访问串口，在解压目录执行 python3 -m http.server 8765 --bind 127.0.0.1，再打开 http://localhost:8765/setup/。
