# Muse Charm v0.8.0 懒人包

仅适用于 Waveshare ESP32-S3-RLCD-4.2，16MB Flash / 8MB PSRAM。
你需要：电脑 Chrome/Edge、USB 数据线、Muse 账号/App、自己的 mgst_ SDK token、2.4GHz Wi-Fi。
千问语音播报另需自己的 Token Plan TTS key，可选。固件不含私人凭证。

## 1. 刷机（不需要 ESP-IDF，不需要编译）

电脑安装 Python 3，然后安装刷机工具：

```sh
python -m pip install esptool
```

macOS / Linux 如没有 python 命令，请将命令中的 python 换成 python3。
关闭串口监视器、配置页面的 USB 连接和其他刷机工具。进入解压目录：

```sh
python -m serial.tools.list_ports
```

记下端口名：Windows 通常 COM3/COM4，macOS /dev/cu.usbmodem…，Linux /dev/ttyACM0。
按住 BOOT，短按 RESET，松开 BOOT，进入下载模式。

新板、其他固件或不确定分区表时，用首次安装镜像；先备份原有设置：

```sh
python -m esptool --chip esp32s3 --port PORT --no-stub write-flash --flash-mode dio --flash-freq 80m --flash-size 16MB 0x0 firmware/muse-charm-v0.8.0-rlcd42-factory.bin
```

已运行 Muse Charm 且分区表一致时，可只更新应用，保留 Wi-Fi、配对和凭证：

```sh
python -m esptool --chip esp32s3 --port PORT --no-stub write-flash --flash-mode dio --flash-freq 80m --flash-size 16MB 0x20000 firmware/muse-charm-v0.8.0-rlcd42-app.bin
```

把 PORT 替换成实际串口名。不要执行 erase-flash，也不要烧写 eFuse。
Factory 是合并镜像，会覆盖 bootloader/分区/OTA 初始化区域；不含 NVS 数据，不会替你擦除旧 NVS。换项目安装时旧设置仍可能存在。
刷完短按 RESET，让板子正常启动。

## 2. 打开配置页面

用电脑 **Chrome 或 Edge** 打开 `setup/index.html`。
如果浏览器限制本地文件串口权限，在解压目录启动本地页面服务器：

```sh
python -m http.server 8765 --bind 127.0.0.1
```

打开 `http://localhost:8765/setup/`。结束后可在终端按 Ctrl+C 关闭。
Safari/Firefox 不支持 Web Serial。页面无外部脚本、无联网请求，不上传凭证。

## 3. 填写自己的凭证

- 点击“连接 USB 设备”，选择 ESP32 USB Serial/JTAG 串口。
- 填写自己的 Muse SDK token：gadgets.muse.ai → Account → SDK tokens。
- 可选填写 Token Plan TTS key。当前支持 qwen-audio-3.0-tts-plus，固定原生 Token Plan TTS 接口。
- 点击“保存并重启”。页面会清空输入框；凭证保存在板子 NVS，断电不丢。
- 页面只报告“已配置”，不读取已保存凭证。格式有效不代表服务权限有效。
- 已配置时留空保留原值。更新 token 需要重启生效；更换账号后请在 Muse App 重新添加设备。

NVS 当前未加密，能物理读取板子 Flash 的人可能获取凭证；不要公开 NVS 转储。清空所有设置时请自行备份，并确认擦除会丢失 Wi-Fi/配对/凭证。

## 4. 手机配对与玩法

Muse App 添加 `MuseGadget-Disp-XXXXXX`，提示时短按 BOOT，选择 2.4GHz Wi-Fi。
按住 KEY 说话、松开发送。BOOT 单击切换主题、双击旋转；长按 5 秒重置配对，设备层的 SDK/TTS key 保留。

可以试说：“切换浅色模式并挥手”“把时区改成上海”“看看 SD 卡里的歌曲”“向左旋转屏幕”。
网络点歌需要 Muse 搜索到直接可播放的 MP3 链接，不支持商业曲库登录/DRM。
电量百分比是电压估算；Q36 手柄连接尚未验证，暂缓调试。
